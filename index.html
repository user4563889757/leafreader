Why this exists

A small site with no bill attached

01

Zero-cost by design

Every page is static HTML, CSS, and JavaScript. Host it on GitHub Pages, Cloudflare Pages, or Netlify's free tier. No database, no container, no AWS trial to expire.

02

Public domain only

The demo library is imported from Project Gutenberg. Each book keeps a link to its source. Add only texts that are public domain or that you have permission to publish.

03

Private by default

Reading progress and theme choices live in your browser's local storage. There are no accounts, cookies, analytics scripts, or third-party fonts.

Bring your own shelf

Add a book in one command

The importer uses only Python's standard library. It pulls a public-domain text from Project Gutenberg, splits it into chapters, and writes plain JSON. 

python3 scripts/import_gutenberg.py \
  --id 2701 --id 345
